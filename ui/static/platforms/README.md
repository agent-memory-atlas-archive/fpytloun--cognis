# Platform logos

Unmodified SVG assets from [Devicon](https://github.com/devicons/devicon),
revision `6a37858047b0e8d9c9c0e68f4a071fc410652e89`:

- `linux.svg`: `icons/linux/linux-original.svg` (Tux)
- `apple.svg`: `icons/apple/apple-original.svg`
- `windows.svg`: `icons/windows11/windows11-original.svg`

The upstream MIT license is included in `LICENSE.devicon`. Logos and trademarks
belong to their respective owners and identify the executor's platform only.
The monochrome Apple asset is inverted with CSS for dark-background contrast.
Assets are served locally, with no third-party image requests.
