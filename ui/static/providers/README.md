# Provider logos

Unmodified SVG brand assets from [Lobe Icons](https://github.com/lobehub/lobe-icons),
pinned to commit `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`.

Source directory: `packages/static-svg/icons/`.
Files: `openrouter.svg`, `openai.svg`, `anthropic.svg`, `codex.svg`.
The upstream MIT license is included in `LICENSE`. Provider names and marks
remain the property of their respective owners.

These assets are bundled locally. No third-party icon requests are made at runtime.
The UI inverts the monochrome logos for its dark background without redrawing them.
