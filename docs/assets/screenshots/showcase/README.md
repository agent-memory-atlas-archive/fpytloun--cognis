# Showcase screenshots

These images render the public Cognis 0.18.2 interface with fictional local
demo data. They are not captures of a real user's workspace. The demo account,
agent, conversation, file changes, approval request, and dashboard metrics are
illustrative; they do not report live execution or release acceptance.

| Image | Viewport | Subject |
| --- | --- | --- |
| `desktop-workspace.png` | 1600 × 1024 | Conversation window with the Work inspector |
| `desktop-diff.png` | 1600 × 1024 | Inline review of a fictional launch manifest |
| `task-approval.png` | 1600 × 1024 | Task cockpit and human approval gate |
| `rich-dashboard.png` | 1600 × 1024 | Built-in rich dashboard with synthetic metrics |
| `mobile-approval.png` | 430 × 932 | Responsive task approval view |

The lossless PNG files contain image data only, without text, EXIF, or other
ancillary metadata. Both the repository README and product showcase reference
these version-controlled assets using relative paths.

When refreshing them:

1. Use an isolated browser and synthetic data, never a private workspace.
2. Use unmistakable demo identities and reserved example email domains.
3. Keep real credentials, operational targets, private paths, and user data out
   of both visible content and image metadata.
4. Inspect every resulting image at full resolution before publication.
5. Retain the fictional-data captions and update all affected image links.
